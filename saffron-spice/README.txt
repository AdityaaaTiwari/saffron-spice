Saffron & Spice Google Sheets integration

The script.js now sends page views, menu filters, cart actions, checkout attempts, reservation requests, and product catalog data to your Apps Script Web App URL.

IMPORTANT: The Apps Script Code.gs must have your spreadsheet ID set, and the deployed web app must be redeployed after code changes. Login events require Supabase Auth integration and are not enabled yet. Checkout and reservations are demo requests, not real payment or confirmed bookings.

Replace the website files in your GitHub repository with index.html, style.css and script.js from this folder, then commit and push to trigger Vercel deployment.
